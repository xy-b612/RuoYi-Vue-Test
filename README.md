# 若依管理系统（RuoYi-Vue）功能测试

> 📌 测试实习作品集 | 测试人：小杨 | 2026.07 - 2026.08

---

## 项目简介

基于 RuoYi-Vue v3.9.2（Spring Boot + Vue 前后端分离后台管理系统）独立完成的功能测试实践，覆盖测试全流程：需求分析 → 测试计划 → 测试用例设计 → 执行 → 缺陷跟踪 → 测试报告。

**被测系统**：[RuoYi-Vue](https://gitee.com/y_project/RuoYi-Vue) — 企业级后台管理系统，包含用户/角色/菜单权限管控、系统监控、代码生成等功能。

---

## 测试范围

| 模块 | 用例数 | 通过率 | 测试重点 |
|------|--------|--------|----------|
| 登录认证 | 28 | 96.4% | 认证/验证码/账号锁定/Token/SQL注入 |
| 用户管理 | 44 | 97.7% | CRUD全链路/导入导出/表单校验/权限控制 |
| 角色管理 | 35 | 100% | CRUD/菜单权限树/数据权限5种范围 |
| **合计** | **107** | **99.1%** | |

**测试维度**：正常 / 边界 / 异常 / 反向 / 兼容

## 缺陷发现

| 等级 | 数量 | 代表性缺陷 |
|------|------|-----------|
| B-严重 | 1 | 查询不存在用户ID → 后端返回空指针异常(500) |
| D-轻微 | 2 | 空搜索多次点击页面刷新；搜索仅支持精确匹配 |

## 技能体现

- 独立搭建 Windows 测试环境（JDK17 + MySQL + Redis + Node.js）
- 需求文档 → 测试计划 → 测试点 → 测试用例 → 缺陷报告 → 测试总结，**全流程闭环**
- 从数据库 DDL 和前端校验规则中挖掘边界值，不依赖需求文档
- 针对 RBAC 权限模型设计**菜单权限树**（全选/半选/父子联动）和**数据权限**（5 种范围联动）专项测试
- 使用 Postman 编写接口测试集，覆盖正常请求 + Token 鉴权 + 异常输入
